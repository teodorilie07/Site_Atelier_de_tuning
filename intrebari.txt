TASK 2 - Afisare + sortare + filtrare + calculare
------------------------------------------------------------
Status: implementat
Fisiere:
- views/pagini/produse.ejs
- index.js
- resurse/js/produse.js

Bloc 1 - formularul de filtre in views/pagini/produse.ejs
- Am un formular cu id="form-filtre" si inputuri pentru nume, pret_min, pret_max, datalist material, radio montaj, checkbox categorii, textarea compatibilitate, select culoare, select multiplu materiale, sortare.
- Asta inseamna ca toate filtrele sunt colectate dintr-un singur formular.

Bloc 2 - filtrarea pe server in index.js
- Functia aplicaFiltre(produse, filtre) primeste lista de produse si obiectul filtre.
- Pentru fiecare filtru se executa o conditie:
  - nume: se compara cu wildcard * si se foloseste normalize() pentru a elimina diacritice.
  - pret_min / pret_max: se filtreaza dupa pret.
  - material_datalist: se compara materialul.
  - montaj: se filtreaza dupa booleanul necesita_montaj_profesionist.
  - categorii: se foloseste un Set pentru a verifica multiple categorii.
  - compat_text: se cauta text in compatibilitate.
  - culoare: se compara culoarea exacta.
  - materiale_multi: se foloseste un Set cu multiple valori selectate.

Bloc 3 - sortarea in index.js
- Functia aplicaSortare(produse, cheie, ordine) creeaza o copie a listei si aplica sort().
- Logica este:
  - dir = ordine === 'desc' ? -1 : 1
  - daca va < vb => return -1 * dir
  - daca va > vb => return 1 * dir
  - altfel => return 0
- Asta inseamna ca daca vrem crescator, returnam -1/1 normal, iar daca vrem descrescator, inversam semnul.

Bloc 4 - fetch-ul client in resurse/js/produse.js
- Se creeaza un obiect FormData din formular.
- Se transforma in URLSearchParams.
- Se face fetch('/catalog-json?' + params.toString()).
- Raspunsul JSON returneaza produse si total.
- Functia renderProduse() reafișeaza cardurile si afiseaza mesajul daca nu exista produse.

Bloc 5 - calculare in resurse/js/produse.js
- Butonul btn-calculeaza asculta click.
- Se iau toate cardurile vizibile.
- Se calculeaza suma preturilor, numarul produselor si total CP.
- Rezultatul apare intr-un div fix de 2 secunde.

INTREBAREA 1 - Cum se face filtrarea?
------------------------------------------------------------
Raspuns:
- Filtrarea se face in index.js, in functia aplicaFiltre(produse, filtre).
- Pentru fiecare camp de filtru se verifica o conditie si se pastreaza doar produsele care trec.
- In client, formularul trimite datele catre /catalog-json prin fetch si JS actualizeaza rezultatele.

------------------------------------------------------------
INTREBAREA 2 - Cum se face sortarea?
------------------------------------------------------------
Raspuns:
- Sortarea se face in index.js, in functia aplicaSortare(produse, cheie, ordine).
- Se creeaza o copie a listei, apoi se aplica sort() cu o functie callback.
- In callback se compara valorile a doua produse si se returneaza -1, 0 sau 1.

------------------------------------------------------------
INTREBAREA 3 - Ce returneaza callback-ul din sort() daca primul argument este mai mic decat al doilea?
------------------------------------------------------------
Raspuns:
- Returneaza un numar negativ, de exemplu -1.
- In codul proiectului se face astfel:
  if (va < vb) return -1 * dir;
- Asta spune ca primul element trebuie pus inaintea celui de-al doilea.

------------------------------------------------------------
INTREBAREA 4 - De ce avem ca argument al functiei de sortare variabila semn (1 sau -1)?
------------------------------------------------------------
Raspuns:
- Variabila dir este semnul directiei sortarii.
- Daca sortam crescator, dir = 1.
- Daca sortam descrescator, dir = -1.
- Astfel se inverseaza ordinea rezultatelor fara a schimba restul logicii.

------------------------------------------------------------
INTREBAREA 5 - Cum se face tema si cum persista pe mai multe pagini?
------------------------------------------------------------
Raspuns:
- In header.ejs se citeste localStorage la incarcarea paginii.
- In theme.js se seteaza atributul data-tuning-theme pe html si se salveaza valoarea in localStorage.
- Deoarece localStorage este global pentru site-ul respectiv, tema ramane si dupa refresh sau dupa navigare pe alta pagina.

------------------------------------------------------------
INTREBAREA 6 - Cum se verifica textarea-ul?
------------------------------------------------------------
Raspuns:
- Textarea are clasa is-invalid daca valoarea are mai putin de 3 caractere.
- Bootstrap arata feedback-ul de invalid.
- In implementarea actuala, validarea este facuta prin conditia din EJS si prin clasa Bootstrap.

------------------------------------------------------------
INTREBAREA 7 - Cum poti selecta un singur buton din grupul de radio buttons?
------------------------------------------------------------
Raspuns:
- Toate inputurile radio au acelasi atribut name.
- Browserul stie ca doar un singur radio poate fi selectat din acel grup.
- In proiect avem name="montaj" si name="sort_ordine".

------------------------------------------------------------
INTREBAREA 8 - Cum se face filtrarea dupa selectul multiplu?
------------------------------------------------------------
Raspuns:
- In views/pagini/produse.ejs, selectul are atributul multiple.
- In index.js, valorile selectate sunt citite ca array si transformate intr-un Set.
- Apoi se verifica daca materialul produsului appartine setului.

------------------------------------------------------------
INTREBAREA 9 - Cum se face meniul dinamic?
------------------------------------------------------------
Raspuns:
- In middleware-ul din index.js se seteaza res.locals.categorii = CATEGORII_ENUM;
- In views/partials/meniu.ejs se parcurge lista categorii cu forEach.
- Astfel meniul este generat din cod, nu scris manual.

------------------------------------------------------------
INTREBAREA 10 - Cum se transforma data din engleza in romana?
------------------------------------------------------------
Raspuns:
- In views/pagini/produs.ejs se definesc doua array-uri:
  - luni = ['Ianuarie', 'Februarie', ...]
  - zileSapt = ['Duminică', 'Luni', ...]
- Se creeaza obiectul Date si apoi se iau: getDate(), getMonth(), getFullYear(), getDay().
- Rezultatul este formatat ca: zi/Luna/an (ziua saptamanii).

------------------------------------------------------------
INTREBAREA 11 - Cum functioneaza filtrarea si sortarea in pagina de produse?
------------------------------------------------------------
Raspuns:
- Formularul trimite inputurile, backend le proceseaza, iar rezultatul e afisat in pagină.
- In plus, JavaScript adauga un comportament modern prin fetch si render la fiecare schimbare de filtru.
- Astfel filtrarea este rapida si se vede imediat.
