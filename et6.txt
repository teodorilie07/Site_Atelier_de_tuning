ETAPA 6 – PAGINA DE PRODUSE / PRODUSE UNICE / FILTRE / SORTARE / DATE DIN BAZA DE DATE

Acest fișier conține blocurile de cod importante din proiect care implementează cerințele din enunț pentru pagina de produse, pagina produsului unic, filtrare, sortare, meniu și datele din baza de date.

--------------------------------------------------------------------------------
1) BAZA DE DATE: tabelele și structura produselor
Proveniență: db/init.sql

Cod relevant:
```sql
CREATE TABLE produse (
    id SERIAL PRIMARY KEY,
    nume VARCHAR(200) NOT NULL,
    descriere TEXT NOT NULL,
    imagine TEXT NOT NULL,
    imagini_extra TEXT[] DEFAULT ARRAY[]::TEXT[],
    categorie categorie_produs NOT NULL,
    material VARCHAR(80) NOT NULL,
    pret NUMERIC(10, 2) NOT NULL CHECK (pret >= 0),
    putere_castigata_hp INTEGER NOT NULL DEFAULT 0,
    data_adaugare DATE NOT NULL DEFAULT CURRENT_DATE,
    culoare VARCHAR(60) NOT NULL,
    compatibilitate TEXT[] NOT NULL DEFAULT ARRAY[]::TEXT[],
    necesita_montaj_profesionist BOOLEAN NOT NULL DEFAULT false
);
```

Explicație linie cu linie:
- CREATE TABLE produse -> creează tabelul principal pentru produse.
- id SERIAL PRIMARY KEY -> cheia primară numerică și unică.
- nume VARCHAR(200) NOT NULL -> numele produsului, obligatoriu.
- descriere TEXT NOT NULL -> descrierea produsului.
- imagine TEXT NOT NULL -> calea către imaginea principală.
- imagini_extra TEXT[] -> vector cu imagini suplimentare pentru produsul unic.
- categorie categorie_produs NOT NULL -> categoria mare, definită prin enumerație.
- material VARCHAR(80) NOT NULL -> o caracteristică „material”, folosită pentru filtrare.
- pret NUMERIC(10,2) -> prețul, valoare numerică.
- putere_castigata_hp INTEGER -> a doua caracteristică numerică.
- data_adaugare DATE -> data calendaristică.
- culoare VARCHAR(60) -> o singură valoare string pentru filtru.
- compatibilitate TEXT[] -> mai multe valori pentru un produs.
- necesita_montaj_profesionist BOOLEAN -> caracteristică booleană.

8) APLICAREA FILTRELOR PE LISTA DE PRODUSE
Proveniență: index.js

Cod relevant:
```js
let filtrate = aplicaFiltre(produse, filtre);
```

Funcția este mai jos:
```js
function aplicaFiltre(produse, filtre) {
  let list = [...produse];
  if (filtre.nume) {
    const raw = normalize(filtre.nume).trim();
    if (raw.includes('*')) {
      const regexStr = '^' + raw.split('*').map(s => s.replace(/[.+?^${}()|[\]\\]/g, '\\$&')).join('.*') + '$';
      const rx = new RegExp(regexStr);
      list = list.filter(p => rx.test(normalize(p.nume)));
    } else {
      list = list.filter(p => normalize(p.nume).includes(raw));
    }
  }
```

Explicație pas cu pas:
- `let list = [...produse]` -> creează o copie a listei de produse.
- `if (filtre.nume)` -> dacă s-a introdus text în filtrul de nume, se filtrează.
- `normalize(...)` -> elimină diacriticele pentru comparație corectă.
- `raw.includes('*')` -> suportă wildcard `*`.
- `regexStr` -> transformă expresia de tip `r*ie` în regex potrivit.
- `list = list.filter(...)` -> păstrează doar produsele care se potrivesc.

Mai departe:
```js
if (filtre.pret_min != null && filtre.pret_min !== '') {
  const v = parseFloat(filtre.pret_min);
  list = list.filter(p => parseFloat(p.pret) >= v);
}
if (filtre.pret_max != null && filtre.pret_max !== '') {
  const v = parseFloat(filtre.pret_max);
  list = list.filter(p => parseFloat(p.pret) <= v);
}
```

Explicație:
- aplică filtrarea după intervalul de preț minim și maxim.

```js
if (filtre.material_datalist) {
  list = list.filter(p => normalize(p.material) === normalize(filtre.material_datalist));
}
```

```js
if (filtre.montaj && filtre.montaj !== 'orice') {
```

9) SORTAREA PRODUSELOR
Proveniență: index.js

Cod relevant:
```js
function aplicaSortare(produse, cheie, ordine) {
  const copy = [...produse];
  const dir = ordine === 'desc' ? -1 : 1;
  const cheiFolosite = Array.isArray(cheie) ? cheie : [cheie];
  copy.sort((a, b) => {
    for (const k of cheiFolosite) {
      let va, vb;
      switch (k) {
        case 'nume': va = a.nume; vb = b.nume; break;
        case 'descriere_lungime': va = (a.descriere || '').length; vb = (b.descriere || '').length; break;
        case 'pret': va = parseFloat(a.pret); vb = parseFloat(b.pret); break;
        case 'putere': va = a.putere_castigata_hp; vb = b.putere_castigata_hp; break;
        case 'data': va = new Date(a.data_adaugare).getTime(); vb = new Date(b.data_adaugare).getTime(); break;
        default: va = a.nume; vb = b.nume;
      }
      if (va < vb) return -1 * dir;
      if (va > vb) return 1 * dir;
    }
    return 0;
  });
  return copy;
}
```

Explicație:
- sortează produsele după una sau mai multe chei.
- `dir` determină dacă este crescător sau descrescător.
- `cheiFolosite` permite să se sorteze după mai multe criterii.

33) TIMERUL PENTRU OFERTE
Proveniență: resurse/js/oferte.js

Cod relevant:
```js
(function() {
  const timers = document.querySelectorAll('.oferta-timer[data-expira]');
  if (!timers.length) return;

  function pad(n) { return String(n).padStart(2, '0'); }
  function format(ms) {
    if (ms <= 0) return '00:00:00';
    const s = Math.floor(ms / 1000);
    const h = Math.floor(s / 3600);
    const m = Math.floor((s % 3600) / 60);
    const sec = s % 60;
    return pad(h) + ':' + pad(m) + ':' + pad(sec);
  }
```

Explicație:
- Transformă timpul rămas în format `HH:MM:SS`.

```js
function tick() {
  const acum = Date.now();
  timers.forEach(t => {
    const expira = parseInt(t.dataset.expira, 10);
    const ramas = expira - acum;
    t.textContent = format(ramas);
    if (ramas <= 10000 && ramas > 0) t.classList.add('critical');
    else t.classList.remove('critical');
    if (ramas <= 0) t.textContent = 'EXPIRAT';
  });
}
```

Explicație:
- Actualizează în fiecare secundă timpul rămas.
- Dacă sunt ultimele 10 secunde, adaugă clasa `critical`.
